One line, max 120 characters — the funniest warning label on a time machine.

## Entry

> WARNING: Do not step on any butterflies. One wrong step and you'll come home to a timeline without Wi-Fi.

## Run

`main.ts` writes that exact line, with no trailing newline, to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`).

```sh
MAKEFUN_OUTPUT_DIR=/tmp/time-machine-warning-out node main.ts
```
